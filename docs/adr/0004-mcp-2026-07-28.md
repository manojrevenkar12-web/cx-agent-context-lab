# 4. Skyline over MCP 2026-07-28: stateless, cache hints, one MCP App

**Decision.** Skyline's tools are served by the v2 TypeScript SDK on the 2026-07-28 revision, built
with `createMcpHandler`. There are no MCP sessions: the conversation is named in an
`x-skyline-conversation` header, and its booking state lives in the backend.

`tools/list` carries `ttlMs` and `cacheScope`. The client negotiates the version (`mode: "auto"`)
and keeps an `InMemoryResponseCacheStore`, so a 154-tool catalogue is fetched once per TTL. A
`show_quote_card` tool renders a quote with Accept and Decline buttons as an MCP App (`ui://`
resource) for chat clients.

**Why.**
- A stateless server scales horizontally behind any load balancer.
- Cache hints remove the per-turn catalogue download that large tool sets otherwise cost.
- The quote card shows how consent can be captured in chat, not just typed.

**Cost.** The SDK is new (v2), and 2025-era clients are served by the legacy fallback.
